## Other ways to help

Money is not the only thing that keeps the project alive:

| How | Why it helps |
|:----|:-------------|
| ⭐ Star the [repository](https://github.com/ferrous-networking/ferrous-dns) | Visibility is what brings new contributors |
| 🐛 [Report bugs](https://github.com/ferrous-networking/ferrous-dns/issues) | Especially on unusual setups — IPv6-only, DNS64, exotic routers |
| 📖 Improve the docs | Fix a typo, clarify a step: use the ✏️ edit link on any page |
| 💬 Answer questions | [Discussions](https://github.com/ferrous-networking/ferrous-dns/discussions) |
| 🔧 Send a PR | See [Contributing](contributing.md) |
